# NS 管理记录快捷查看

在 NodeSeek 帖子各楼层的操作菜单中加入「⚖️ 管理记录」，按需查看该账号的公开管理记录。基于 [NS 管理记录快捷查看 0.5.0](https://api.xxboxx.de/ns-seek.user.js) 独立维护，保留 MIT 许可与来源说明。

## 安装

1. 安装 [Tampermonkey](https://www.tampermonkey.net/)（建议使用当前稳定版）。
2. 点击 **[安装脚本](https://raw.githubusercontent.com/xinian5216/ns-seek/main/ns-seek.user.js)**，在扩展中确认安装。
3. 如果曾安装原版，先停用原版，避免两个脚本同时运行。独立维护版使用新的命名空间，需要单独安装。
4. 打开 `https://www.nodeseek.com/post-*` 帖子，点击楼层操作区的「⚖️ 管理记录」，阅读提示，再点击「同意并查询」。

更新来自本仓库的 `main` 分支；`ns-seek.meta.js` 仅含版本头，`ns-seek.user.js` 为完整脚本。可在 Tampermonkey 中手动检查更新。发布版本可在 [Releases](https://github.com/xinian5216/ns-seek/releases) 查看。

## 功能与改进

- 使用原站当前网页采用的 `/v1/user?q=uid:…` 接口，按 UID 查询，减少改名影响。没有自动回退到旧接口或其他服务。
- 打开帖子和打开弹窗都不会查询，明确同意后才发出单次匿名请求。
- 不读取论坛 Cookie，不传送当前帖子地址，不保存查询历史、记录或同意状态；关闭弹窗清空结果。
- 不含密钥输入位、统计、广告、远程依赖或外部图标；仅申请固定 API 域名的一项跨域请求权限。
- 接口内容以文本渲染；链接仅允许论坛的 HTTPS 帖子地址，去除查询参数并限制新窗口权限。
- 15 秒超时；关闭或切换账号取消请求，忽略旧响应；限速后必须手动重试。
- 每批显示 30 条，不为翻页增加网络请求。最多处理 5000 条，接口或本地截断都会提示，不把索引结果当作完整记录。
- 支持动态加载楼层、迟到的作者信息、数字和含空格的显示名；窗口支持系统明暗主题、窄屏与原生对话框的键盘交互。

## 隐私边界

**独立维护脚本不等于独立数据服务。** 数据仍由第三方 `api.xxboxx.de` 提供。点击同意查询后，该服务及其网络服务商可获知访问 IP、所查询 UID、请求时间和常规 HTTP 元数据；本项目无法验证服务端日志、保留期限或使用方式。脚本不提供匿名网络，也不能隐藏访问 IP。

脚本通过 Tampermonkey 的 `anonymous: true` 请求模式避免携带 API 域名 Cookie，清空 Referer 并拒绝重定向。只有 UID 作为查询参数，不额外发送用户名或帖子地址。浏览器与脚本管理器实现仍需在你的实际环境验证。详见 [PRIVACY.md](PRIVACY.md) 和 [审计记录](AUDIT.md)。

GitHub 和浏览器扩展的安装、更新检查有其各自的网络与隐私行为；本脚本不控制它们。仓库归属于公开 GitHub 账号，账号与项目的关联会公开。

## 限制与验证

第三方索引可能延迟、遗漏或停止服务；无查询结果不能证明没有管理记录。接口不是本项目控制的稳定契约，未来可能变化。论坛楼层结构变化也可能影响按钮定位。

已用虚构用户名验证当前接口 HTTP 200 与未找到结果的响应；没有抓取真实账号作为测试数据。DOM 回归测试使用合成页面与模拟响应。论坛对自动访问返回验证页面，因此**尚未完成真实登录浏览器里的油猴端到端验证**；安装后请检查按钮位置、弹窗、实际查询和跨域权限。其他脚本管理器、移动端与旧浏览器尚未验证。

## 维护

开发需要 Node.js 22.22.2 以上的 22.x、24.15 以上的 24.x 或 26 以上版本，运行脚本无需 Node.js 或 npm。

```sh
npm ci --ignore-scripts
npm run check
npm test
```

改版本时同步 `package.json` 和脚本 `@version`，再运行 `npm run build` 更新元数据。提交前检查差异，确保 Git 身份使用 GitHub noreply 邮箱。CI 会核对版本、更新来源、隐私约束，运行交互测试并用 Gitleaks 扫描完整历史。

不自动合并原作者脚本，不远程执行原站 JavaScript。手动更新接口时先核对公开网页行为，使用合成数据补充测试。报告问题不要提交 Cookie、令牌、浏览器配置、网络抓包或未脱敏截图。
