# NS 管理记录快捷查看

**VPS 自动采集，按 UID 查询私人封禁档案。** 只保留最近 365 天的封禁、解封记录，到期自动清理。不依赖原作者的查询 API。源码公开，真实档案与凭据私有。

## 日常使用

1. 打开[私人面板](https://ns.042804.xyz:8443)，输入专属访问密码。
2. 首次使用 VPS 自动采集时，点击「打开 VPS 浏览器」，在原网页正常登录论坛或完成验证，再点击「验证并启用自动同步」。不需要导出电脑 Cookie。
3. VPS 默认每 **6 小时**检查新增记录；历史每次最多补采 200 个编号，分批完成后间隔 15 分钟继续。启用后可以关闭电脑。登录失效、验证、限速、网络或格式错误时暂停，需人工处理并恢复。
4. [安装或更新油猴脚本](https://raw.githubusercontent.com/xinian5216/ns-seek/main/ns-seek.user.js)，在面板的「电脑采集（备用）」中连接一次，用于查询授权。之后在帖子点击用户的「管理记录」即可查档案，无需每次手动采集。

面板每 5 秒显示状态、当前页／历史编号、已检查数量、保留数量与下次计划。检查数量增加但封禁数量不变，可能是在过滤普通操作。初次补采可能很久，不承诺完整历史。

**远程浏览器控制页用于登录／验证，打开它会暂停采集**，避免人工操作与任务冲突。处理完点击「验证并启用自动同步」返回面板。平时只看面板，无需打开控制页。画面默认适应窗口，可切换原始大小；点击画面后键盘输入、Tab、Enter 和滚轮可操作，也可通过下方遮蔽输入框发送文本。

电脑手动采集仍可作为备用：配对成功后手动点击同步，并保持论坛标签页运行。自动配对失败时可复制面板的一次性连接码，粘贴到论坛脚本弹窗。连接跳转使用当前标签页，不依赖弹出窗口。

## 私人访问与轮换

面板采用独立复杂密码；只存 scrypt 随机盐和摘要。会话 Secure、HttpOnly、SameSite=Strict，八小时到期。油猴只得到独立查询与同步密钥，没有远程浏览器权限。

「更换密码并撤销旧连接」可生成复杂密码，请先保存在密码管理器。更换后旧面板会话、配对码与全部 API 密钥失效，需要重新连接油猴。远程浏览器画面与输入必须有当前有效的面板会话，查询、同步或本地管理 Bearer 令牌均不能访问；正在等待返回的截图也会重新检查会话是否已撤销。

密码轮换不会删除论坛浏览器的登录状态，也不停止已经授权的后台任务。需要暂停采集可点击面板的暂停按钮，需要退出论坛请在 VPS 浏览器中正常退出。

## 数据范围与隐私

仅保存最近 365 天封禁／解封事件的编号、UID、当时显示名、管理员显示名、时间、帖子编号和操作原因。纯奖励／扣分不入档；其他事件只记数字检查断点，不保存身份字段。每小时物理清理，查询即时过滤到期记录；SQLite 启用 secure_delete，并在删除后截断 WAL。不创建数据备份，云厂商快照和系统虚拟内存不由数据库保留策略管理。

电脑 Cookie 不导出。VPS 采集使用独立 Chromium 的浏览器管理会话，在论坛同源页面读取固定 ruling page/id 路径，不读取 Cookie 字符串，不绕过验证、不伪装浏览器指纹。远程登录的输入经自己的 HTTPS 服务转交浏览器，仅在内存中处理；不保存论坛明文密码、截图、输入或访问日志。

浏览器配置位于私有目录，和数据库一样不进入 Git 或安装包。数据库、浏览器配置和系统交换空间不做磁盘加密；root、服务账户及有磁盘访问权者仍能读取相应内容。本项目不承诺对已被控制的 VPS、电脑或泄露密码的隔离。详见[隐私说明](PRIVACY.md)。

## 首次采集与覆盖范围

先读最近列表（每页 20 条，最多 100 页），验证 `/api/admin/ruling/id-N` 后按编号从新到旧补采。连续 20 条成功读取且早于一年的有效记录后停止；依赖编号和时间的大致顺序，不能证明历史完整。

采集请求串行，每次完成后至少等待 1.2 秒。失败不会记成空记录，也不进行后台定时重试；任务会持久化暂停原因，直到所有者明确恢复。成功空响应只保存数字断点，不能证明记录从未存在。查询无匹配只代表目前已存档范围没有找到。

## 维护

Node 22.23.2，内置 SQLite，零 npm 运行时依赖；官方 Debian Chromium、chromium-sandbox 与 Xvfb 提供正常浏览器，不使用 headless、关闭沙箱、指纹伪装或验证绕过工具。

- 应用代码：`/opt/ns-seek/app`；数据库、密码摘要、定时状态：`/var/lib/ns-seek`（0700）。
- 浏览器配置：`/var/lib/ns-seek-browser`（0700），独立服务账户；禁用保存密码、下载、同步和自动填充。
- CDP 仅监听 `127.0.0.1:9222`；后端仅监听 `127.0.0.1:18765`。HTTPS 使用 8443，保留原有 443 入口，不开放调试端口。
- [应用服务](deploy/ns-seek.service)、[浏览器服务](deploy/ns-seek-browser.service)、[浏览器启动](deploy/start-browser.sh)、[策略](deploy/chromium-policy.json)、[Caddy](deploy/Caddyfile)。安装 native 包后创建独立服务账户和私有目录，再启用两个服务。
- 应用重启保留数据库、计划和暂停状态；面板需重新登录。浏览器会话保留在其私有配置中。运行环境以 `NS_SEEK_BROWSER=1` 启用服务器采集功能。
- 浏览器保留 512MiB 内存硬上限和 512MiB 交换上限，不设置会导致持续回收的低软限制。VPS 增加 1GiB、0600 权限的持久交换文件作为峰值缓冲。任务发现可用物理内存低于 96MiB 会暂停。

开发：`npm ci --ignore-scripts`、`npm run check`、`npm test`、`npm audit --audit-level=low`。测试使用合成记录和模拟浏览器，不使用真实账号或既有配置。发布仅取 Git 跟踪文件，并扫描全历史、安装包与已知生产凭据；浏览器配置、数据库、密码、截图与输入不得加入仓库。
