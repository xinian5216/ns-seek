# NS 管理记录快捷查看

在 NodeSeek 帖子各楼层的操作菜单中加入「⚖️ 管理记录」，**使用浏览器当前的论坛登录状态直接读取站内记录，在本地按 UID 筛选**。从 1.1.0 起不再使用第三方查询服务，无跨域请求权限，无需填写、导出或上传 Cookie。

基于 NS 管理记录快捷查看 0.5.0 独立维护，保留 MIT 许可与[来源说明](THIRD_PARTY.md)。

## 安装与升级

1. 安装 [Tampermonkey](https://www.tampermonkey.net/)（建议使用当前稳定版）。
2. 点击 **[安装或更新脚本](https://raw.githubusercontent.com/xinian5216/ns-seek/main/ns-seek.user.js)**，在扩展中确认。已安装 1.0.0 的用户也可在扩展中检查更新；命名空间与更新地址不变。请升级到 1.1.0 或更新版本，旧版仍使用第三方接口。
3. 如果曾安装原作者版本，先停用原版，避免重复运行。
4. 在同一个浏览器中登录 NodeSeek，并确认能打开[论坛管理记录页](https://www.nodeseek.com/ruling)。
5. 打开 `https://www.nodeseek.com/post-*` 帖子，点击楼层菜单的「⚖️ 管理记录」，再点「查询最近 5 页」。需要更早记录时手动继续。

更新来自本仓库 `main` 分支；`ns-seek.meta.js` 仅含版本头，`ns-seek.user.js` 为完整脚本。[Releases](https://github.com/xinian5216/ns-seek/releases) 提供固定版本与 SHA256 校验值。

## 查询方式与范围

脚本按需请求站内 `/api/admin/ruling/page-N`，浏览器自动携带论坛登录状态。目标 UID 只在本地用于筛选，不作为请求参数发送；显示名变动不影响按 UID 匹配。没有第三方回退、站长密钥或后台数据服务。

- 每轮最多读取 **5 页**，每次完成请求后至少等待 **1.2 秒**才读取下一页；跨批次或切换用户也保留间隔。
- 每轮后暂停，继续需再次点击。可随时「停止本轮」，保留已完成的页并从未完成页继续；关闭或切换账号则取消请求、清空此次查询。
- 当前实现按每页 20 条、最多 100 页处理。理论最多检查约 2000 条全站记录；**这不是目标用户的全部历史记录**。100 页/20 条依据现有客户端对站点接口的实现，当前登录环境仍需核验。
- 明确显示已检查页数和匹配数量。无匹配只代表已读取范围没有找到；遗漏 UID、总数变动或达到上限时会提示。
- 读取期间总数变化可能导致分页移动，按记录 ID 去重仍无法保证没有遗漏。
- 匹配结果每次显示 30 条，「显示更多已匹配记录」只展开本地数据，不增加请求。
- 单次请求 15 秒超时；未登录、浏览器验证、格式变化、网络错误或限速都会停止，不自动重试。限速等待期间再次点击也不会发请求。

## 隐私与安全

运行时查询仅访问 NodeSeek 本站：`@grant none`，没有 `@connect`、远程依赖、统计或外部图标。不读取 `document.cookie`，不保存 Cookie、查询历史或记录；正常登录 Cookie 由浏览器仅向本站携带。请求禁止跨域、拒绝重定向，不附带 Referer。

论坛及其网络服务商仍能识别你的登录账号、访问 IP、请求页码和时间。这不是匿名访问。你现有的其他扩展和页面代码仍可能观察页面活动。

接口内容只以文本显示；原帖和原记录链接仅由有效数字 ID 在本地构造，打开新窗口使用 `noopener noreferrer`。GitHub 托管脚本更新，扩展检查更新会涉及 GitHub 网络请求，和运行时查询是不同过程。

详见 [PRIVACY.md](PRIVACY.md) 与 [AUDIT.md](AUDIT.md)。

## 验证与限制

自动测试使用合成论坛页面和模拟响应，不包含真实账号记录或登录凭据。当前开发环境直接访问论坛仍遇到浏览器验证，因此**尚未完成真实登录浏览器里的油猴端到端验证**。接口契约来自开源客户端的实际实现，不是论坛面向第三方承诺的稳定 API，未来可能变化。

安装后应在正常登录浏览器中检查按钮、弹窗、读取结果和分页范围。遇到 HTTP 401/403/500 或非 JSON 页面，先打开论坛管理记录页确认登录和验证状态，再手动继续。不要把 Cookie、HAR 抓包或未脱敏截图提交到 Issues。其他脚本管理器、移动端与旧浏览器尚未验证。

## 维护

开发需要 Node.js 22.22.2 以上的 22.x、24.15 以上的 24.x 或 26 以上版本；使用脚本无需 Node.js 或 npm。

```sh
npm ci --ignore-scripts
npm run check
npm test
```

同步修改 `package.json` 和脚本 `@version`，再运行 `npm run build` 更新元数据。CI 核对版本、更新来源与同源隐私约束，运行交互测试、依赖审计和 Gitleaks 全历史扫描。提交身份使用 GitHub noreply 邮箱。

不自动合并上游，不远程执行其他脚本，不自动批量读取 100 页，不尝试管理员搜索权限。接口变化需核对实际站点行为，并用合成数据补充测试。
